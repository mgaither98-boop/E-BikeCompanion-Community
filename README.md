Welcome to the public community space for **E-Bike Companion**. Use this repository to report app issues, contribute bike compatibility observations, and help improve documentation.

**Website:** https://ebike.magservers.org

**Tester sign-up note:** the website form opens a prefilled GitHub issue or an email draft for you to review and submit. It is not an automatic mailing list, and test access is not guaranteed. Do not put private contact details into a public GitHub issue.

## Important safety and privacy principles

- E-Bike Companion is designed around offline-first and local-first use. Do not assume reports or app data are uploaded automatically.
- Only submit information you choose to share, after reviewing the contents.
- Never post passwords, access tokens, private keys, exact GPS coordinates, GPX files, home/work locations, or unredacted diagnostic exports.
- Do not post serial numbers or other unique identifiers unless a maintainer explicitly requests a safer alternative.
- Compatibility reports are unverified until reviewed and clearly marked.
- Experimental drivers remain **read-only**. This repository is not a place to request or distribute unreviewed commands that change motor, braking, throttle, speed-limit, or other safety-related settings.

## What this repository is for

This repository is for community issue tracking and reviewed evidence. It is not the app's source repository, and submitting an issue does not guarantee that a feature will be implemented or a device will be supported.

Please be respectful and provide only evidence you have permission to share.
