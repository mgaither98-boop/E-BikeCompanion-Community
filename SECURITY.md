# Security policy

## Reporting a security concern

Please do not publish exploit details, credentials, access tokens, private keys, personal data, or instructions that could put riders at risk in a public issue.

This repository is a public community tracker, not a confidential security-reporting channel. The project has not yet published a verified private security contact. Until one is published on https://ebike.magservers.org, do not attach secrets or sensitive diagnostic files to GitHub issues. You may open a minimal issue asking for a private reporting route without including technical details that expose a vulnerability.

## Scope

Security concerns may include accidental disclosure of private ride/location data, unsafe Bluetooth command behaviour, credential exposure, or a vulnerability affecting app users.

## Safety

Do not exploit a vulnerability on another person's device or bike. Do not test while riding or issue commands that could affect motor output, braking, throttle, speed limits, or other safety-related behaviour.
