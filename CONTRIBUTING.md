# Contributing to E-Bike Companion

Thank you for helping improve E-Bike Companion. Useful, careful evidence is more valuable than assumptions.

## Before opening an issue

1. Search existing issues for the same problem or bike configuration.
2. Use the bug report or compatibility report template.
3. Include the app version/build and Android version when relevant.
4. Separate what you directly observed from what you infer.
5. Review every field and attachment before submitting.

## Do not submit

- Passwords, API keys, access tokens, private keys or account recovery information.
- GPS coordinates, home/work locations, route history, GPX files or ride recordings.
- Unredacted diagnostic exports, screenshots with notifications/personal details, or device identifiers.
- Other people's personal data or information you are not authorised to disclose.
- Proprietary firmware dumps or copyrighted files you do not have permission to share.

If you believe an export contains sensitive information, do not upload it. Describe the issue without the file and ask for guidance.

## Compatibility evidence

Include exact make/model/year, display/controller identifiers and firmware versions only when safe and known. State whether a result was repeated and which app version was used. Do not infer support from a similar-looking bike.

Do not test while riding. Never experiment with braking, throttle, motor output, speed limits, or other safety-related functions as part of an issue report.

## Driver and control safety

Experimental drivers must remain read-only. Community reports may inform research, but an issue or comment is not authorisation to add write commands, bypass interlocks, or make safety-critical changes. Driver changes require separate review, evidence, and appropriate testing before any capability claim is made.

## Public issue visibility

Issues in this repository are public. Do not post anything you would not want publicly visible. You can edit or close an issue, but copies may remain in notifications, forks, archives or other systems. For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
